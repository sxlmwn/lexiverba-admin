# LexiVerba Courier Portal — Build Prompt

I'm attaching a ZIP file called `lexiverba-donezo-main.zip`. This is the **LexiVerba Agency Portal** — our official, finalized design system. I need you to build a **brand new Courier Portal** that uses **100% the exact same design system, theme, colors, fonts, components, and animations** as this zip — but for a completely different purpose (couriers doing document delivery/notary jobs instead of a translation agency dashboard).

## 1. Tech stack (match the zip exactly)

- React 19 + TypeScript + Vite
- Tailwind CSS v4 (via `@tailwindcss/vite`, `@import "tailwindcss";` in index.css — NOT a tailwind.config.js setup)
- `lucide-react`, `clsx`, `tailwind-merge` as dependencies
- Google Fonts: **Inter** (weights 400–900) for all text
- **Material Symbols Outlined** (Google Fonts icon font) for every icon — same `font-variation-settings: 'FILL' 0, 'wght' 600, 'GRAD' 0, 'opsz' 24` rule as in the zip's `index.css`
- Single-page app pattern: one `App.tsx` holds `currentTab` state and renders pages conditionally (no router needed, but React Router is fine if you prefer — just keep the same visual shell)

## 2. Design tokens — copy these exactly from the zip

**Dark mode** (`.dark` class on `<html>`):
- Base background: `#09090b`
- Sidebar/header surface: `#121215`
- Borders: `#27272a`
- Text: `slate-100` / white

**Light mode** (default):
- Base background: `#f4f7ff`
- Text: `#001033`
- Sidebar/header surface: white, border `slate-200/80`

**Accent & semantic colors:**
- Primary accent: `blue-600` (buttons, active states, active-nav indicator bar, focus rings, glow shadows)
- Success/positive: `emerald-500`
- Warning/pending: `amber-500`
- Danger/overdue: `rose-500`
- Optional highlight: `purple-500`

**Shape & motion language (reuse these exact utility classes/effects from `index.css`):**
- Rounded corners: `rounded-2xl` / `rounded-3xl` everywhere (cards, buttons, inputs, avatars, badges)
- `.smooth-card` — GPU-safe rounded card with `backface-visibility: hidden` and `2.5rem` radius
- `.float-shadow` — soft floating box-shadow under cards (different opacity for light/dark)
- `.float-hover` — on hover: `translateY(-6px)` + blue glow shadow + blue border, NO scale transform
- `.badge-shadow`, `.badge-glow-emerald`, `.badge-glow-amber`, `.badge-glow-rose`, `.badge-glow-purple` — colored glow shadows for status badges/pills, lift 2px on hover
- `@keyframes pageEnter` (`.animate-page-enter`) — fade+slide-up entrance for each page (opacity 0→1, translateY 10px→0, 0.35s)
- `@keyframes cardPop` (`.animate-card-pop`) — fade-in for cards/list items
- `animate-pulse` / `animate-ping` for live indicators (online status dot, unread notification dot)
- Scrollbars hidden globally (`::-webkit-scrollbar { display: none; }`)
- All color/background transitions: `transition-colors duration-300`

## 3. Shell layout (copy structure from `App.tsx`, `Sidebar.tsx`, `Header.tsx`)

  - Notifications bell with unread-count dot (ping animation) → dropdown panel showing recent activity
  - User profile menu (avatar with online-status ring, name + role subtitle) → dropdown panel with profile/settings/theme-toggle/sign-out
- **Main content area**: `pl-72`/`pl-20` (matches sidebar width), `pt-28 px-10 pb-16`, each page wrapped in `.animate-page-enter`
- **Floating AI Assistant**: reuse the same floating chat-bubble component pattern (bottom-right circular button that opens an assistant panel)
- **Modals**: reuse the same `InteractiveModal` pattern — rounded-3xl, `border-2`, `shadow-2xl`, animated in/out — for any confirmation, upload, or detail popups
